# 레퍼런스 영상 분석 (`reference/` 13개)

## 기본 스펙
- 세로 9:16, 30fps, H.264 + AAC 44.1kHz 스테레오
- 길이 11~35초, 대부분 약 30초

## 촬영
- 같은 세트, 고정 카메라 한 대 (인물 정면, 손에 작은 마이크)
- 화면 전환, 줌, 카메라 이동 없음

## 컷 편집
- 점프컷: 30초에 약 23~26번, 평균 1.2~1.3초마다 한 번
- 말 사이 쉬는 구간과 숨소리를 전부 잘라서 말이 쉬지 않고 이어짐

## 화면 요소 (위 → 아래)
| 요소 | 위치 (세로 %) | 스타일 |
|---|---|---|
| 제목 | ~15% | 흰색 굵은 명조체, 어두운 그림자, 가운데 정렬, 1~2줄, 영상 내내 고정 |
| TOP 5 패널 | ~47%~75% | 반투명 흰색 둥근 사각형, `1.`~`5.` 번호, 항목은 작은 검정 글씨 |
| 자막 | ~78% | 흰 배경 박스 + 검정 고딕, 짧은 구절(대략 15자 이하) 하나씩, 약 1초씩 |

- TOP 5 항목은 **5위부터 1위 순서**로, 말하는 시점에 타이핑 효과로 채워짐
- 목록 대신 그래픽 스티커를 쓰는 변형도 있음 (예: `퇴직금.mp4`의 달력 364/365/366 DAYS + X 표시)

## 대본 구조 (TOP 5 형식)
1. 훅: "○○ TOP 5 정리해 보자 / 특히 마지막 1위는 … / 바로 알려주세요"
2. "5위는?" → 설명 → "4위는?" → … → "2위는?"
3. "마지막 1위 맞춰 볼래? 힌트는 …" → 1위 공개

## 오디오
- 목소리 평균 약 -18 dB RMS
- 목소리 아래에 BGM이 계속 깔림 (바닥 소음 약 -27~-29 dB)

## 자동화 대응
| 레퍼런스 요소 | 자동 처리 방법 |
|---|---|
| 점프컷 | 원본 음성에서 무음과 숨소리 감지 → 잘라내기 (FFmpeg, 음성 구간 감지) |
| 자막 | Whisper(오프라인)로 음성 인식 → 짧은 구절로 나눠 타이밍 맞추기 |
| TOP 5 항목 등장 | 음성 인식 결과에서 "5위", "4위" … 를 찾아 그 시점에 항목 표시 |
| 제목, 항목 텍스트 | 사용자가 입력 (또는 음성 인식 결과에서 추천) |
| BGM | 사용자 음악 파일 + 목소리가 나올 때 BGM 볼륨 자동으로 낮추기 |

# 추가 레퍼런스: 질문·답변형 (`1. 알바 직장내괴롭힘.mp4`, `4. 퇴사연차 15개.mp4`)

## 기본 스펙
- 앞 영상들과 같음 (세로 9:16, 30fps), 길이 37~42초
- 다른 세트(흰 책장 배경), 고정 카메라, 인물 정면

## 구성
- **대본:** "노무사님, ○○ 되나요?" 로 묻고 → "결론부터 말하면 …" 으로 답한 뒤 → 조건·예외 → 대처 방법
- **목록 패널 없음**
- **제목:** 같은 명조체 두 줄, 질문 형태 ("알바생도 직장 내 괴롭힘 / 신고할 수 있을까")
- **자막:** 앞 영상과 같은 위치·스타일 (흰 박스 + 검정 글씨)

## 그림 스티커
- 말하는 내용에 맞는 3D 그림이 **자막 바로 위(세로 약 68%)** 에 잠깐씩 나타남
  - 예: 근무 → 시계와 직원, 괴롭힘 → 상사가 몰아세우는 그림, 상시근로자 5명 → 사람들, 연차 15개 → 달력 15, "응 줘야 해" → 체크
- 크기 약 300px(1080 기준), 한 번에 하나, 2~4초씩, 영상 앞쪽에 더 많이 나옴

## 자동화 대응
| 레퍼런스 요소 | 자동 처리 방법 |
|---|---|
| 그림 스티커 | 자막 속 키워드 → 스티커 33종(Fluent 3D 이모지)에서 골라 톡 튀어나오는 효과로 표시, 너무 잦지 않게 간격 조절 |
| 질문형 제목 | 첫 문장에서 "노무사님," 같은 부르는 말을 빼고 추천 |
| 목록 없음 | 순위·순서 표현이 없으면 목록 패널을 자동으로 끔 |

# 추가 레퍼런스: 나열형 3가지 (`2. 육아휴직 지원금.mp4`, `3. 정부지원금.mp4`)
- "첫째, 둘째, 셋째"로 3가지를 나열 → 기존 나열형 그대로 처리
- 목록 패널은 **5줄일 때와 같은 크기**를 유지하고, 3줄을 패널 가운데(첫 줄 y≈1064, 간격 104)에 모음
- 제목은 두 줄, 첫 줄이 약간 더 김 ("직원이 육아휴직 내면 무조건 / 신청해야 하는 지원금 3가지")
- 끝에 "더 자세하게 알고 싶어? 팔로우하고 댓글 남겨주면 내가 정리한 자료 보내줄게" 같은 마무리 멘트 (자막만)

# 추가 레퍼런스: O/X 퀴즈형 (`5. 근로 상식 퀴즈.mp4`)
- 제목 한 줄 ("일상 근로 상식 퀴즈"), 다른 배경(흰 벽 + 화분)
- 문제: "…라고 하면 해고 효력이 없다?" 처럼 **"~다?"로 끝나는 문장**
- 문제를 말하기 시작하면 가운데(중심 y≈1258)에 **가로 540 × 세로 300 사진 카드**가 나타나고,
  답을 말하기 시작하면 카드 위에 **초록 원 체크(O)** 또는 **빨간 X**가 크게(약 220px) 나타남
- 카드는 다음 문제가 나올 때까지 유지

| 레퍼런스 요소 | 자동 처리 방법 |
|---|---|
| 문제 찾기 | "~다?"로 끝나는 문장 (영상 앞에 "퀴즈"가 있으면 2문제부터, 없으면 3문제부터 퀴즈형으로 판단) |
| 정답 | 답 첫마디가 "O/맞아/응" → O, "X/아니/땡" → X, 없으면 질문과 답 문장의 부정 표현("안/없/못/무효")을 비교해 추측 |
| 사진 카드 | 기본은 흰 카드 + 질문 키워드에 맞는 3D 스티커, 사진 파일을 지정하면 사진 카드 |
