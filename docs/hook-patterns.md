# 참고 영상 도입부 후킹 멘트 유형 정리

`reference/` 28개 영상의 첫 3~9초 자막을 모두 읽고 유형별로 묶었습니다.
프로그램은 영상을 분석할 때 도입부가 어떤 유형인지 자동으로 알아보고 창 위쪽 상태 줄에 보여줍니다 (`reels_auto/hooks.py`).

## 유형별 상세

### 1. TOP N 예고형 (가장 많이 씀)
**틀:** `[주제] TOP 5 정리해 보자` → `특히 (마지막) 1위는 [손해·공감 자극]` → `바로 알려주세요!` → `5위는 …`

1위 떡밥 문장 (실제 사용 예):
- 나중에 땅 치고 후회해 (1. 근로계약서 Top5)
- 나중에 분쟁 생겼을 때 가장 중요해 (근로계약서)
- 진짜 조심해야 돼 (노동법)
- 직빵이야 (노동청신고)
- 하는 순간 손절이야 (연봉협상)
- 모든 직장인들이 한 번쯤은 들어봤어 (연차)
- 장난이었다고 하는 경우가 많아 (직장 괴롭힘)
- 거의 퇴사 확정이야 (퇴사 직전)
- 수백만 원 차이 날 수 있어 (퇴사 챙길 돈)

주제 문장에 쓰는 강한 단어: **호구되는**, **망치는**, **반드시 챙겨야 하는**, **가장 많이 착각하는**, **신고 당하기 쉬운**

### 2. 노무사님 질문형
**틀:** `노무사님, [구체적 상황]이면 [행동]해도 되나요? / 무슨 차이예요? / 뭐가 그렇게 달라져요? / 이유가 뭐예요?` → 즉답

즉답·반전 문장:
- 결론부터 말하면 … (1. 알바 직장내괴롭힘)
- 아니, 이게 대표님들이 가장 많이 오해하는 부분 중 하나야 (2. 수습기간)
- 엄청 큰 차이인데 대표님들이 가장 많이 헷갈려 해 (5. 권고사직)
- 응 줘야 해 (4. 퇴사연차 15개)
- 이 5가지가 달라져 / 이 5가지 이유가 가장 많아 → 바로 알려주세요! (6. 직원 5명, 3. 병원)

변형 — **짧은 대화극**: "갑자기 안 나온대?" → "네 그냥 잠수탔는데요?" (7. 무단퇴사), "왜요? 수습기간이면 그냥 잘라도 되는 거 아니에요?" (2. 수습기간)

### 3. 되묻기 공감형
**틀:** `[상황]이라고? / [불만] 별로 없지?` → `[혜택] N가지 정리해줄게` → `첫째, …`
- 직원이 육아휴직 들어갔다고? → 무조건 신청해야 하는 육아휴직 사업주 지원금 3가지 정리해줄게
- 지원금 엄청 많은데 받을 수 있는 건 별로 없지? → 쉽게 받을 수 있는 직원 채용 정부 지원금 3가지 정리해줄게

### 4. 숫자·돈 계산형
**틀:** `[금액] 직원 뽑으면 실제로 얼마 나가요?` → 항목별 금액 빠르게 나열 → `아니 아직` → 추가 비용 → 총액
- 월급 300만 원 직원 뽑으면 회사에서 실제로 얼마 나가요? → 국민연금 13만 5천 원, 건강보험 10만 6천 원 … → 안 줘도 최소 월 355만 원 나가

### 5. 오해 깨기(비교 반전)형
**틀:** `[조건 A] → [결과]` → `[조건 B] → [뜻밖의 결과]` → `단순히 ○○이 아니라 ○○이 중요해`
- 364일 근무하고 퇴사하기 → 퇴직금 안 나와 → 365일 근무하고 퇴사하기 → 퇴직금 안 나올 수 있어 (퇴직금)
- 개인 사정으로 회사 결근 → 연차, 휴가 사용 → 주휴수당 받아 / 못 받아 (주휴수당 기준)

### 6. 지금 받아 적어형
**틀:** `이 N가지 중 하나에 해당되면 [이득]` → `지금 당장 받아 적어` → `1. … 2. … 3. …`
- 이 3가지 중 하나에 해당되면 연장 근로수당 안 줘도 될 수 있어. 지금 당장 받아 적어 (8. 야근수당)

### 7. 바로 본론형
인트로 문장 없이 제목 자막만 띄우고 곧바로 첫 내용부터.
- 퀴즈: 카카오톡으로 "내일부터 나오지 마세요" 라고 하면 해고 효력이 없다? (5. 근로 상식 퀴즈)
- 티어: S-tier / C-tier 판정부터 (9·10. 직장태도 티어)

## 공통 패턴
- **대상이 둘로 나뉨:** 대표님(사업주)용 — 지원금, 해고, 수습, 부담금 / 직장인용 — 퇴사, 연차, 주휴수당, 괴롭힘
- **손해를 피하게 하는 말투:** 호구, 후회, 손절, 수백만 원, 신고, 분쟁
- **반말 + 짧은 문장:** "정리해 보자", "알려줄게", "받아 적어"
- **첫 3초 안에 주제 + 떡밥**이 모두 나옴. 인사말("안녕하세요")은 한 번도 없음

## 마무리(CTA) 멘트
- 더 자세하게 알고 싶어? 팔로우하고 댓글 남겨주면 내가 정리한 자료 보내줄게 (지원금 영상)
- 댓글에 "권고사직" 달면 양식 보내줄게 (5. 권고사직)
- 이해 못 한 부분이 있으면 바로 전화해 / 병원 노무 세팅 전략 궁금하면 바로 연락 줘 (8. 야근수당, 3. 병원)
- 꼭 해야 되는 3가지가 있거든? 전화하면 바로 알려줄게 (2. 수습기간)
