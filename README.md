# 취업규칙 검토·개정 프로그램

## 1. 법령 다운로드

국가법령정보센터 Open API로 노동 관계 법령을 조문 단위로 내려받습니다. 파이썬 3.8 이상이면 별도 설치 없이 실행됩니다.

```
python download_laws.py --oc 내인증키
```

- `--law 근로기준법 --law 최저임금법`처럼 원하는 법령만 받을 수 있습니다.
- 결과는 `laws/` 폴더에 저장됩니다.
  - `*.xml`: API 원본 응답
  - `*.json`: 조문 단위로 정리한 데이터
  - `articles.csv`: 전체 조문 목록 (엑셀에서 바로 열림)
- Open API 신청 때 등록한 IP의 PC에서만 동작합니다.

출처: 국가법령정보센터(www.law.go.kr)
