# 사업용 통장 거래내역 관리 프로그램

개인사업자 사업용 통장의 입출금 내역을 관리하는 개인용(로컬) 프로그램입니다.
전체 설계는 [DESIGN.md](DESIGN.md)를 참고하세요.

## 실행 방법 (Windows)

### 1. Python 설치

Python 3.11 이상이 필요합니다. [python.org](https://www.python.org/downloads/)에서
설치할 때 "Add python.exe to PATH" 옵션을 반드시 체크하세요.

### 2. 필요한 패키지 설치

프로젝트 폴더에서 명령 프롬프트(cmd)를 열고 아래 명령을 실행합니다.

```
pip install -r requirements.txt
```

### 3. 프로그램 실행

`run.bat` 파일을 더블클릭하면 자동으로 브라우저가 열리며 프로그램이 실행됩니다.

또는 명령 프롬프트에서 직접 실행할 수도 있습니다.

```
streamlit run app.py
```

실행 후 자동으로 열리지 않으면 브라우저에서 `http://localhost:8501` 주소로 접속하세요.

### 4. 데이터 위치

- 거래 데이터는 프로젝트 폴더 안의 `data/finance.db` 파일에 저장됩니다.
- 이 파일은 Git에 올라가지 않도록 `.gitignore`에 등록되어 있습니다.
- **다른 PC로 옮기거나 백업하려면 `data` 폴더를 통째로 복사해두면 됩니다.**

## 거래내역 조회 / 수정 / 삭제 방법

좌측 메뉴에서 **거래내역**을 선택하면 저장된 모든 거래를 표로 확인할 수 있습니다.

### 조회 / 검색 / 필터

- **검색 / 필터** 영역에서 시작일·종료일·수입/지출·카테고리·거래처·업무유형·증빙 여부를
  원하는 대로 조합해서 좁혀볼 수 있습니다 (여러 조건을 동시에 적용 가능).
- **거래내용 검색**에 "KT"처럼 일부 단어만 입력해도 포함된 거래를 모두 찾아줍니다.
- 조건을 다시 처음 상태로 되돌리려면 **필터 초기화** 버튼을 누르세요.
- 표 위쪽 **검색 결과 요약**에 현재 필터 기준 조회 건수·총수입·총지출·순금액이 표시됩니다.
- 조건에 맞는 거래가 하나도 없으면 "조건에 해당하는 거래내역이 없습니다."라고 안내합니다.

### 수정

1. 거래 목록 아래의 **수정 또는 삭제할 거래 선택** 드롭다운에서 원하는 거래를 고릅니다.
2. **✏️ 선택한 거래 수정** 버튼을 누르면 기존 값이 미리 채워진 수정 창이 열립니다.
3. 필요한 항목을 고쳐서 **저장**을 누르면 반영됩니다.
4. 거래일자/수입·지출/거래내용/금액은 필수 항목이며, 금액은 0원보다 큰 값만 저장됩니다.
5. **수입 ↔ 지출을 변경하면 카테고리 선택이 자동으로 비워집니다.** 기존 유형의 카테고리가
   그대로 남지 않으니, 새 유형에 맞는 카테고리를 다시 선택해주세요.

### 삭제

1. 위와 동일하게 드롭다운에서 거래를 선택합니다.
2. **🗑️ 선택한 거래 삭제** 버튼을 누르면 "OO 거래를 삭제하시겠습니까?" 확인 창이 뜹니다.
3. 내용을 확인한 뒤 **삭제**를 눌러야 실제로 지워지며, **취소**를 누르면 아무 변화 없이 창만 닫힙니다.

## 대시보드 사용법

좌측 메뉴 **대시보드**에서 사업용 통장의 수입·지출·순현금흐름과 매출 구조를 한눈에 확인할 수 있습니다.

### 조회 기간

- **빠른 선택**: 이번 달 / 지난달 / 최근 3개월 / 올해 / 직접 선택 중 고를 수 있습니다.
  - **이번 달**: 이번 달 1일 ~ 오늘
  - **지난달**: 지난달 1일 ~ 지난달 마지막 날 (한 달 전체)
  - **최근 3개월**: 이번 달을 포함해 최근 3개월(이번 달 1일 기준 2개월 전 1일) ~ 오늘
  - **올해**: 올해 1월 1일 ~ 오늘
  - **직접 선택**: 시작일/종료일을 직접 지정 (종료일이 시작일보다 빠르면 오류 메시지를 표시하고 계산을 중단합니다)

### KPI 카드와 직전 기간 비교

- 상단에 **총수입 / 총지출 / 순현금흐름(총수입-총지출) / 거래건수** 4개를 표시합니다. 모두 DB의 INTEGER 값을 그대로 합산한 값이며, float으로 변환하지 않아 1원 단위까지 정확합니다.
- 각 카드 아래에는 **직전 비교기간**(선택한 기간과 정확히 같은 일수만큼, 선택 기간 바로 이전) 대비 증감을 보여줍니다.
  - 총수입: 증가하면 초록(▲), 감소하면 빨강(▼) — 늘어나는 게 좋은 지표
  - 총지출: 증가하면 빨강, 감소하면 초록 — **색상 기준이 총수입과 반대**입니다 (지출은 느는 게 나쁜 신호이므로)
  - 순현금흐름: 퍼센트가 아닌 **원 단위 증감액**으로 표시합니다 (마이너스로 전환되는 경우 등 퍼센트 비교가 오히려 헷갈릴 수 있어, 금액 차이 하나만 명확한 기준으로 사용)
  - 거래건수: 증감률만 참고용으로 표시(색상 의미 없음)
  - 직전 비교기간의 데이터가 아예 없는 값(0)은 비교 자체가 무의미하므로 증감 표시를 생략합니다.
- 바로 아래 보조 지표로 **수입/지출 거래 건수**와 **평균 수입/지출 거래금액**을 표시합니다. 건수가 0이면 평균은 "-"로 표시하고 오류를 내지 않습니다.

### 차트

1. **월별 수입·지출 추이**: 선택 기간에 걸친 월별 수입/지출을 막대로 비교합니다.
2. **지출 카테고리별 금액**: 선택 기간의 지출만 대상으로 금액이 큰 순서대로 표시하며, 금액과 전체 대비 비중(%)을 함께 보여줍니다.
3. **업무유형별 매출**: 선택 기간의 수입만 대상으로 업무유형별 합계를 금액이 큰 순서대로 표시합니다.
4. **거래처별 매출 TOP 10**: 선택 기간의 수입만 대상으로 거래처별 합계 상위 10곳을 표시합니다.

세 카테고리/업무유형/거래처 차트 모두 **해당 항목이 지정되지 않은 거래는 '미분류'라는 이름으로 합산해서 함께 표시**합니다(제외하지 않습니다). 개인 사용 프로그램 특성상 아직 분류하지 못한 금액도 눈에 보이는 것이 낫다고 보고 이 방식을 기본값으로 정했습니다. (`db/dashboard_repository.py`의 `UNCLASSIFIED_LABEL` 참고)

- 지출이 0건이면 지출 카테고리 차트 자리에 "지출 데이터가 없습니다."를, 수입이 0건이면 업무유형/거래처 차트 자리에 "수입 데이터가 없습니다."를 표시합니다.
- 선택 기간에 거래가 하나도 없으면 KPI/차트 전체 대신 "해당 기간에 거래내역이 없습니다."만 표시합니다.

### 최근 거래내역

대시보드 맨 아래에 선택 기간 기준 최근 거래 10건을 거래일자→거래시간→id 내림차순으로 보여줍니다.

## 현재 개발 단계

**3단계: 대시보드** 까지 구현되어 있습니다.

- 거래처 관리 / 설정 화면은 아직 "준비 중입니다" 안내만 표시됩니다.
- 거래등록 → 거래내역(조회·검색·필터·수정·삭제) → 대시보드까지 이어지는 핵심 흐름을 사용할 수 있습니다.

전체 개발 단계는 [DESIGN.md](DESIGN.md)의 "6. 단계별 개발계획"을 참고하세요.

## 테스트 실행 방법 (개발자용)

실제 데이터를 건드리지 않는 임시 DB를 사용해 자동 검증 스크립트를 실행할 수 있습니다.

```
python tests/test_stage1.py
python tests/test_stage2.py
python tests/test_stage3.py
```

세 스크립트 모두 `tests/` 폴더 아래에 임시 DB 파일을 만들어 사용하고,
종료 시 자동으로 삭제하므로 `data/finance.db`는 절대 읽기/쓰기/삭제하지 않습니다.

화면을 직접 눈으로 확인하고 싶다면, 실제 데이터 대신 별도의 DB 파일을 가리키게 해서
안전하게 띄워볼 수 있습니다 (Windows cmd 기준):

```
set FINANCE_DB_PATH=C:\temp\test_finance.db
streamlit run app.py
```

`FINANCE_DB_PATH`를 지정하지 않으면 평소처럼 `data/finance.db`를 사용합니다.
