# 릴스 자동 편집 (Windows · 무료 · 오프라인)

직접 찍은 원본 영상을 넣으면 레퍼런스(`reference/`)와 같은 스타일의 릴스로 자동 편집합니다.

## 자동으로 해주는 것
1. **점프컷** – 말 사이 쉬는 구간을 모두 잘라서 템포를 빠르게
2. **자막** – 음성 인식(Whisper, PC 안에서 동작)으로 짧은 구절 자막 자동 생성
3. **목록** – 말하는 순간에 목록 항목이 타이핑되듯 나타남. 2~7개까지 자동으로 개수를 맞춤
   - **순위형** (TOP 3, TOP 5 …): "3위는? … 2위는? … 1위" → 아래 줄부터 채움
   - **나열형** (꼭 챙겨야 할 3가지 …): "첫 번째 … 두 번째 … 마지막으로" → 위 줄부터 채움
   - **퀴즈형** (O/X): "…라고 하면 해고 효력이 없다?" 같은 문제마다 가운데에 그림 카드가 뜨고, 답을 말하면 ✅ / ❌ 가 톡 튀어나옴 (정답은 "O", "맞아", "아니" 같은 말이나 문장 뜻으로 자동 추측)
   - **티어리스트** (S/A/B/C): "욕설, S티어" 처럼 말하면 색 칸(S 빨강 · A 주황 · B 노랑 · C 초록) 줄에 항목이 옆으로 붙음
   - **질문·답변형** (목록 없음): "노무사님, ○○ 되나요?" 처럼 묻고 답하는 영상은 목록 없이 자막 + 그림 스티커로
4. **제목** – 첫 문장으로 추천 (순위형이면 "○○ TOP N", "노무사님," 같은 부르는 말은 뺌)
4-1. **그림 스티커** – 자막에 "연차", "퇴직금", "신고" 같은 말이 나오면 그에 맞는 3D 그림(달력, 돈주머니, 확성기 …)이 톡 튀어나옴 (33종, 목록이 없는 영상에서 자동)
5. **배경음악** – 기본 BGM 3곡 포함, 말할 때 음악 소리를 자동으로 줄임
6. **얼굴 자동 보정** – 얼굴 위치를 찾아서 그 부분만 피부 결을 자연스럽게 정돈하고, 볼·턱선을 살짝 갸름하게 (끄기/약하게/보통/강하게)
7. 세로 1080×1920, 30fps mp4로 저장

## 설치
1. 이 저장소의 **Releases** 에서 최신 `ReelsAuto-windows.zip` 을 받습니다.
2. 압축을 풀고 폴더 안의 `ReelsAuto.exe` 를 실행합니다.
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 누르세요 (서명 안 된 무료 프로그램이라 뜨는 경고입니다).
3. 설치나 인터넷 연결은 필요 없습니다. 그래픽카드가 없어도 됩니다.

## 사용법
1. **① 원본 영상 고르기** – 폰으로 찍은 세로 영상 (가로 영상은 가운데를 잘라 세로로 만듭니다)
2. **② 자동 분석** – 30초 영상 기준 보통 1~3분 걸립니다
3. 추천된 **제목 / 목록 항목 / 자막** 을 확인하고 틀린 글자를 고칩니다
   - 자막은 한 줄이 화면에 한 번 나오는 자막입니다. 줄 수를 그대로 두고 글자만 고치면 타이밍이 유지됩니다.
   - 목록 형식(순위형/나열형/표시 안 함)과 개수는 직접 바꿀 수 있습니다.
   - 목록 항목의 "나타나는 시점(초)"을 바꾸면 목록에 글자가 나오는 순간이 바뀝니다.
   - 그림 스티커는 한 줄에 "시점(초) 이름" (예: `3.5 달력`) 으로 추가·수정하고, 줄을 지우면 안 나옵니다.
   - 스티커 · 퀴즈 카드 · 티어리스트는 오른쪽 아래 탭에서 고칩니다.
   - 티어리스트는 한 줄에 "시점(초) 등급 글자" (예: `3.2 S 욕설`).
   - 퀴즈 카드는 한 줄에 "문제 시작 정답 공개 O/X 그림" (예: `1.5 4.8 O 휴대폰`). 그림 자리에 사진 파일 경로를 쓰면 레퍼런스처럼 사진 카드가 됩니다.
4. **배경음악**, 음악 크기, **얼굴 자동 보정** 강도(기본: 약하게)를 고르고 **③ 영상 만들기** 를 누릅니다.

## 도입부 후킹 멘트
레퍼런스 28개의 도입부를 7가지 유형으로 정리했습니다 → [`docs/hook-patterns.md`](docs/hook-patterns.md)
(TOP N 예고형 · 노무사님 질문형 · 되묻기 공감형 · 숫자·돈 계산형 · 오해 깨기형 · 지금 받아 적어형 · 바로 본론형)
분석이 끝나면 창 위쪽에 이 영상의 도입부 유형이 표시됩니다. 대본을 쓸 때 참고하세요.

## 촬영 팁 (자동 편집이 잘 되려면)
- 레퍼런스처럼 **고정 카메라** 로 찍으면 점프컷이 티 나지 않습니다.
- "3위는?", "첫 번째는", "1번은" 처럼 **순위나 순서를 또렷하게 말하면** 목록이 자동으로 채워집니다.
- 첫 문장에서 "TOP 3", "3가지" 처럼 **개수를 말해주면** 개수를 더 정확히 맞춥니다.
- 주변 소음이 적을수록 컷과 자막이 정확합니다.
- 얼굴이 정면을 향하고 너무 작지 않으면 얼굴 보정이 잘 됩니다. 얼굴을 못 찾으면 밝기·혈색만 살짝 보정합니다.
- 음성 인식이 전문 용어를 틀리게 적을 수 있으니(예: "근로계약서"), 만들기 전에 제목과 자막을 한 번 훑어보세요.
- 자주 틀리는 단어는 `assets/words.txt` 에 한 줄씩 적어두면 다음부터 더 잘 알아듣습니다 (노동법 용어 30여 개가 기본으로 들어 있음).

## 내 음악 넣기
`assets/bgm` 폴더에 mp3를 넣으면 목록에 나옵니다. 또는 프로그램에서 **직접 고르기...** 를 누르세요.
무료 음원은 YouTube 오디오 보관함 등에서 받을 수 있습니다 (각 음원의 사용 조건을 확인하세요).

## 개발자용
```
pip install -r requirements.txt
python -m reels_auto                  # 프로그램 창
python -m reels_auto 원본.mp4         # 창 없이 추천값 그대로 만들기
```
Windows exe는 GitHub Actions(`.github/workflows/build-windows.yml`)가 자동으로 만들어 Releases에 올립니다.
