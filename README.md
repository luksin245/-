# 취업규칙 검토·개정 프로그램

취업규칙 PDF를 올리면 노동 관계 법령을 기준으로 다음을 처리하는 웹 프로그램입니다.
- 필수 기재사항(근로기준법 제93조)이 빠졌는지 점검
- 법령 위반이 의심되는 조항 점검
- 법 개정 반영: 취업규칙 기준일(부칙의 시행일) 이후 바뀐 법 조문과 관련 취업규칙 조항 찾기 (시행 예정 포함)
- 신구대조표 작성(Word): 점검 결과로 개정안 초안을 만들거나, 개정본 PDF와 비교

## 처음 한 번: 법령 내려받기

```
python download_laws.py --oc 내인증키
```

- 국가법령정보센터 Open API로 법령을 받아 `laws/` 폴더에 저장합니다.
- 2018년 이후의 개정 이력(시행 버전별 조문)도 `laws/versions/`에 받습니다. 더 이전부터 필요하면 `--since 20150101`처럼 지정하세요.
- 처음에는 개정 이력 때문에 몇 분 걸리고, 다음부터는 새로 생긴 버전만 받습니다.
- Open API 신청 때 등록한 IP의 PC에서만 동작합니다.
- 법령이 개정되면 다시 실행해서 갱신하세요.

## 실행

**`run.bat`를 더블클릭**하면 필요한 패키지를 설치하고, 브라우저에서 http://localhost:8501 을 엽니다.

직접 실행할 때:
```
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## 파일 구성

| 파일 | 역할 |
|---|---|
| `download_laws.py` | 법령 다운로드 |
| `app.py` | 웹 화면 |
| `rule_parser.py` | PDF 텍스트 추출, 조항 분리 |
| `checks.py` | 필수 기재사항·위반 점검 규칙 |
| `law_db.py` | 내려받은 법령 데이터 조회 |
| `law_changes.py` | 기준일 이후 법령 개정 비교, 관련 조항 찾기 |
| `revision.py` | 신구대조표 초안 작성, 개정본 비교, Word 내보내기 |

## 주의

- 키워드와 숫자를 기준으로 한 1차 점검이며, 법률 자문이 아닙니다.
- 스캔한 이미지 PDF는 읽을 수 없습니다.

출처: 국가법령정보센터(www.law.go.kr)
